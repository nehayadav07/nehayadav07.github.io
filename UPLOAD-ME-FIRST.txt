NEHA — PORTFOLIO SITE
=====================

Same structure as the other build, so nothing here is new to you.

PUBLISH
  1. github.com -> New repository -> Public -> no README
     Name it <yourusername>.github.io to serve from the root.
  2. Add file -> Upload files -> drag the FILES INSIDE this folder
     (not the folder itself) -> Commit to main.
  3. Settings -> Pages -> Deploy from a branch -> main -> / (root)
  4. Live in 1-2 minutes.

BEFORE YOU SHARE IT
  Search js/content.js for [[  -- 33 placeholders are waiting.
  The ones that matter most, in order:

  1. LinkedIn URL           (appears 3 times)
  2. Resume PDF path        (appears 3 times)
  3. iF Design Award        which project, which year
  4. NID                    degree and years
  5. Career timeline        3 or 4 of your strongest roles
  6. The three "what I'd do differently" closers
  7. Cover images           one per case study

  Everything else already reads as a finished site.

THEME
  css/theme.css holds the Editorial Organic palette and the
  Playfair / Lora / DM Sans stack. The hex values are my
  approximation of Forest Ink, Grow Teal and Heritage Gold --
  swap in your real ones, then re-check contrast.

CONTACT FORM
  Off by default. Set contact.form.endpoint in admin to switch
  it on. See README.md.
